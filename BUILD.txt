MI7 Guild - APK banane ka tareeqa

A) Android Studio (GitHub ke baghair)
 1. Is zip ko extract karen.
 2. Android Studio > Open > extract hua folder (jis mein build.gradle.kts aur app/ ho).
 3. Gradle sync hone den.
 4. Build > Build Bundle(s) / APK(s) > Build APK(s)
 5. APK: app/build/outputs/apk/debug/app-debug.apk

B) GitHub Actions
 Poora folder GitHub Desktop se publish karen (.github, app, supabase wagairah sath).
 Actions tab > Build APK > Artifacts > MI7Guild-apk

Package: com.free.mi7guild (google-services.json se match)
